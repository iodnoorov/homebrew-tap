# iodnoorov/tap

Формулы Homebrew для программ [iodnoorov](https://github.com/iodnoorov).

## ymusic

Терминальный клиент Яндекс Музыки — [github.com/iodnoorov/ymusic](https://github.com/iodnoorov/ymusic).

```bash
brew install iodnoorov/tap/ymusic
```

Ставится готовый бинарник из релиза: на macOS — для Intel или Apple Silicon, на Linux — статический (x86_64, aarch64).
Обновление — `brew upgrade ymusic`.
